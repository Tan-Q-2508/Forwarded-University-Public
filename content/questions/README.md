# Question bank (not included)

The real, verified question bank is private. Put your own approved questions here as JSON matching
`../schema/question.schema.json`, then run `npm run import:local`.
`../samples/example-question.json` shows the format and is marked EXAMPLE ONLY.
For a quick local game with synthetic TEST content, use `npm run dev:full` (sets `DEV_CONTENT=1`).
